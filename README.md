# GarbhaSaathi (गर्भसाथी) 🌸
### A Personalized Pregnancy Nutrition, Mood Wellness & Daily Self-Care Web Portal
> **"Your Companion for a Healthy, Happy Pregnancy Journey"**

---

## 💻 Website Portal (Full-Fledged Website with Left Sidebar)

GarbhaSaathi features a **Fixed Left Navigation Sidebar** and a modern, well-organized healthcare dashboard!

### Main Website Layout (Sidebar Navigation):
The left sidebar provides 7 main sections in a fixed order:
1. **🏠 Dashboard**
2. **👶 My Journey**
3. **🥗 Nutrition Plan**
4. **🎙️ Voice Check-in**
5. **🧘 Mind & Mood**
6. **📋 Records & Reminders**
7. **⚙️ Settings**

#### Section Details:

2. **👶 Pregnancy Journey & Month-Wise Guide:**
   - Complete physical and fetal development details from Month 1 to Month 9.
   - Key nutrients to focus on (Iron, Folate, Calcium, Water).
   - Essential clinical tests for each month (ANC visits, NT scan, TIFFA anomaly scan).

3. **🥗 Nutrition Planner & Kitchen Pantry:**
   - Budget selection: Low (₹) / Medium (₹₹) / High (₹₹₹).
   - Home ingredient checklist (rice, wheat, milk, eggs, lentils, vegetables, fruits).
   - Safe home remedies for Morning Sickness/Nausea (ginger-lemon water, dry crackers, roasted makhana).
   - Health benefits across 6 nutritious food categories.

4. **🎙️ AI Voice Saathi & Health Check-in:**
   - Speak symptoms in Hindi, Marathi, or English using the Web Speech API.
   - Quick symptom selection (Good, Nausea/Vomiting, Fatigue, Weakness, Mood Changes).
   - Instant comfort and dietary advice spoken back via Text-to-Speech in your chosen language.

5. **🧘 Mind & Mood Wellness Hub (Garbha Sanskar):**
   - 6 mood emojis (Happy 😊, Calm 🧘, Tired 🥱, Anxious 😟, Stressed 😣, Sad 😢).
   - 4-7-8 Breathing Pranayama audio player with Inhale–Hold–Exhale animation.
   - Read-aloud story and book reader (Font Zoom In/Out + Read Aloud in Marathi/Hindi/English).
   - Short wellness reels video player.

6. **📋 Health Records & Smart Medicine Reminders:**
   - Drag-and-drop report uploader (PDF / Image).
   - Smart OCR to detect hemoglobin levels, sonography dates, and doctor prescriptions.
   - Medicine reminders activate only after confirmation by the user.

7. **⚙️ Profile & Settings:**
   - Auto-calculate Expected Delivery Date (EDD) from Last Menstrual Period (LMP).
   - 1-click secure JSON backup download of all data.

8. **📱 View Mode Switcher:**
   - Toggle between **"Website"** portal view and **"Mobile Mockup"** at the bottom-right corner.

## 🌟 Special Features for Expecting Mothers

Thoughtfully designed tools for real pregnancy needs:

1. **👣 Baby Kick Counter:**
   - Session timer for 10 kicks in 2 hours.
   - 1-tap kick counter with confetti celebration animation on 10 kicks.
   - Medical guidelines for normal and safe fetal movement.

2. **💧 Hydration Water Tracker:**
   - Visual wave animation for 8–10 glasses of water per day.
   - Tips to prevent amniotic fluid issues, leg cramps, and UTIs.

3. **🚨 Emergency Danger Signs & SOS (108 Helpline):**
   - Instant recognition of serious symptoms (bleeding, severe headache, blurred vision, facial swelling, reduced fetal movement).
   - 1-click call to **108 (National Ambulance)** and **102 (Free Janani Shishu Ambulance)**.

4. **🧘‍♀️ Breathing Pranayama Audio Player:**
   - 4-7-8 breathing cycle (Inhale–Hold–Exhale) animation to instantly calm blood pressure and pregnancy anxiety.

5. **📖 Read-Aloud Story & Book Reader:**
   - Font size adjustment (Zoom In / Zoom Out).
   - Text-to-Speech (TTS) narration in Marathi, Hindi, and English.

6. **📄 Smart OCR Report Analysis & Medicine Confirmation Modal:**
   - Detects dates and hemoglobin values from uploaded lab reports or sonography scans.
   - Medicine reminders activate only after user confirmation of doctor's prescription.

7. **📱 15-Screen Presentation Navigator (Screen Switcher Bar):**
   - 1-click switch to any of the 15 screens from the top toolbar at any time.

8. **🎙️ AI Voice Saathi (Multi-lingual Conversational Assistant):**
   - Powered by Google Gemini AI.
   - Understands and responds in Hindi, Marathi, and English.
   - Conversational, context-aware responses to all pregnancy-related questions.
   - Voice input via microphone and voice output via Text-to-Speech.

## 🚀 How to Run the Project

### 1. Open the Folder in VS Code
Open VS Code and select:
`File` ➔ `Open Folder...` ➔ Choose `C:\Users\ASUS\GarbhaSaathi`

---

### 2. Start the Frontend
Open a new terminal in VS Code (`Ctrl + ~` or `Terminal` ➔ `New Terminal`):

```powershell
cd frontend
npm install
npm run dev
```

You will see a link in the terminal:
👉 **`http://localhost:5173`**
(Open this in your browser — the app will be running live!)

---

### 3. Start the Backend FastAPI Server (Optional)
Open a second terminal in VS Code (click the `+` button):

```powershell
cd backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

👉 Backend APIs: **`http://localhost:8000`**
👉 Interactive Swagger Documentation: **`http://localhost:8000/docs`**
